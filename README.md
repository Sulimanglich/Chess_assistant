# Chess Assistant

Плавающая панель + захват экрана + стрелка лучшего хода (Stockfish).

## Сборка APK
**GitHub Actions (без Android Studio):** залейте проект в репозиторий → вкладка Actions → "Build APK" →
артефакт `ChessAssistant-debug-apk`. Workflow сам скачивает Stockfish.

**Android Studio:** `bash get_stockfish.sh` (кладёт `libstockfish.so` в `app/src/main/jniLibs/arm64-v8a/`),
затем Build → Build APK(s).

## Использование
1. Запустить → выдать «Поверх других окон» и захват экрана.
2. Открыть партию. Нажать **Начать**: при первом запуске тапнуть левый верхний и правый нижний угол доски,
   затем тап внутри сетки. Для запоминания фигур на экране должна быть начальная расстановка.
3. Дальше всё автоматически: приложение следит за доской и при вашем ходе рисует оранжевую стрелку.
4. ☰ → «Цвет»: Авто (определяет сторону сама) / Белые / Чёрные; «Выбрать доску», «Запомнить фигуры», «Стоп».
   ⏸ — пауза, ✕ — закрыть. Панель тянется за любую кнопку.

После смены темы фигур или размера доски повторите «Выбрать доску» и «Запомнить фигуры».
Stockfish распространяется под GPLv3.
